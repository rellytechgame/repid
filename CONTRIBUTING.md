# Contributing to RePID Identity

Thank you for helping make RePID better! The **source code is private**, so code pull requests are not accepted — but there are great ways to contribute, and all of them matter.

*El código fuente es privado, así que no se aceptan pull requests de código, pero hay varias formas de contribuir.*

## 🐛 Report a bug · Reportar un error

[Open a bug report](https://github.com/rellytechgame/repid/issues/new/choose) and include:

- Your operating system and version (e.g. Windows 11 23H2).
- The RePID version (shown in *About*).
- What you did, what you expected, and what happened.
- If a process was misidentified: its name and, if you can, its file path.

## 💡 Request a feature · Pedir una función

[Open a feature request](https://github.com/rellytechgame/repid/issues/new/choose) and tell us the problem you want solved — not just the solution. What would make RePID indispensable for you?

## 🌐 Translate RePID · Traducir RePID

RePID is available in Spanish and English. Each language is a single file of short texts.

- [Open a translation request](https://github.com/rellytechgame/repid/issues/new/choose) for your language and we'll add it, crediting you.
- The format is described in [docs/ADDING_A_LANGUAGE.md](docs/ADDING_A_LANGUAGE.md); you can prepare the texts and attach them to the issue.
